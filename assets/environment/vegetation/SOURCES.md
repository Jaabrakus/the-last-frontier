# Package C vegetation assets: sources and processing

Everything in this folder is generated by the scripts in `tools/environment/vegetation/`
(deterministic, re-runnable). Poly Haven inputs are CC0 1.0 (see `assets/polyhaven/LICENSE.txt`
and `MANIFEST.json`); they are read from `assets/polyhaven/` and never modified. The procedural
parts (branch skeletons, leaves, needles, birch bark) are original to this project.

| Folder | What | Made by | Poly Haven inputs |
|---|---|---|---|
| `bark/` | `bark_conifer_albedo_2k` (white pine, hemlock: darker, red-brown, moss toned down, mean linear luminance 0.075), `bark_hardwood_albedo_2k` (oak, maple: grey, 0.095), `bark_normal_2k` and `bark_arm_2k` (copies) | `make_textures.py` (`bark()`) | `bark_brown_02` (Diffuse, nor_gl, arm) |
| `bark/birch_*_1k` | paper-birch bark: cream base (never above 0.85 sRGB), lenticels, peeling strips, branch-scar chevrons; normal from a height field | `make_textures.py` (`birch()`) | none (procedural) |
| `foliage/foliage_albedo.png`, `foliage_normal.png`, `foliage_tiles.json` | 2048 x 3072 card atlas, 4 x 6 tiles of 512 px: white pine, hemlock, oak, maple, birch, hazel sprays (2 each), early-red maple, dead pine twig, fir sapling side view, shrub_04 sprig, and 8 dense "clump" tiles (7-10 sprays fanned, premultiplied compositing, 31-49 % coverage) for the far LODs. Every tile also has a hexagonal cutout (`hull`) the cards use instead of the full quad. Tile 14 (fir sapling) is available but not used by the current meshes | `build_atlas.py` (Blender, Cycles emission renders: albedo x local AO, and the normal pass) + `assemble_atlas.py` (packing, clumps, push-pull padding) | `fir_sapling` (tile 14, rendered from the side with its own twig / branch textures); `shrub_04` (tile 15, with the alpha rebuilt by `make_textures.py`; used by the hazel shrub variant 2) |
| `trees/<species>.glb`, `trees.json` | white pine, hemlock, oak, maple, birch (3 variants x 3 LODs), saplings (pine, hemlock, maple, birch) and a hazel shrub (3 variants x 2 LODs). One surface per mesh: bark tubes + atlas cards; vertex colour = baked AO / outer-crown / random / foliage flag, UV2 = branch wind data. `trees.json`: heights, crown model, trunk collider size, triangles per LOD | `build_trees.py` (Blender) | none (procedural, textured with the files above) |
| `impostors/impostor_albedo.png`, `impostor_nrm.png`, `impostors.json` | 8-view impostors of the canopy trees (10 rows: pine v0 / v2, hemlock v0 / v2, oak v0 / v1, maple v0 / v1, birch v0 / v1), 256 x 512 per view, albedo with AO + view-space normal | `bake_impostors.gd` (Godot, windowed, `shaders/vegetation/tree_bake.gdshader`) + `assemble_impostors.py` | none |
