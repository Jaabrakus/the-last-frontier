# Wildlife stand-in models (Quaternius, CC0)

Stand-ins for the first playable wildlife (2026-09-26). Our own detailed animals (built with the horse system,
tools/horse) will replace them behind the same behaviour code (scripts/wildlife).

- Author: Quaternius (https://quaternius.com), "Ultimate Animated Animal Pack" / "Animated Animal Pack"
- Licence: CC0 1.0 (public domain), as stated on each model's Poly Pizza page. No attribution is required;
  we credit the author anyway (CREDITS.md).
- Downloaded 2026-09-26 with the owner's approval, from Poly Pizza's file server (the pack's Google Drive
  folder answered "Quota exceeded"). Files are unmodified.
