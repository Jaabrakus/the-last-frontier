# Reference docs: the anime look of the four elements

Written 2026-10-16 by the element team's reference finder, for the four element chats (earth, water, fire, air)
and the lead. The owner's brief (2026-10-16): redo the game's element effects "as close to Anime Style Avatar:
The Last Airbender as possible": not the fighting styles' clips, but HOW EACH ELEMENT IS GATHERED from its
surroundings and shaped into a cast.

| File | What it holds |
|---|---|
| `avatar_bending_style.md` | The look shared by all four: cel colour and line, 2D timing (anticipation, snap, hold, follow-through), smears and multiples, impact frames, effects drawn as shapes, each element's palette, reading against the background, what Korra's era adds. |
| `avatar_earth.md` | Earth: how it is lifted or torn from the ground; pillars, boulders, slabs, armour, fissures; timing; how it ends; reference moments; links; mapping to our moves. |
| `avatar_water.md` | Water: how it is drawn from a source in a ribbon that follows the arms; whip, stream, octopus form, wave, ice; timing; how it ends; reference moments; links; mapping. |
| `avatar_fire.md` | Fire: produced from breath and strikes, not gathered; punches, kicks, arcs, whips, breath, walls, lightning; timing; how it ends; reference moments; links; mapping. |
| `avatar_air.md` | Air: gathered by circular sweeps and compressed; blasts, air ball and scooter, sphere, slicing arcs, gusts; timing; how it ends; reference moments; links; mapping. |

## The rule

Describe, never copy. No image, frame, GIF, clip or fan-made asset of the show enters this repository, ever; links
and words only. Nothing was downloaded, screenshotted into the repo or traced for these docs. Every effect in the
game is our own shaders, meshes and particles (see `AGENTS.md` on provenance). These docs use the show's words
(the names of the arts, the characters, the places) because they are reference notes, not player text: player-facing
strings never use them (`tests/ring/test_player_words.gd` lists the held words).

## How the docs were made

- The Avatar Wiki's four art pages (Waterbending, Earthbending, Firebending, Airbending) were read in full in the
  browser pane on 2026-10-16; their technique lists are the backbone of each element doc's move list.
- The martial-arts basis and the production process come from the show's co-creators and its martial-arts
  consultant (links in the style doc).
- Scene descriptions (what a whip's tip does, how a slab rises) are written from memory of the episodes and are
  marked "from memory" where the wiki does not state them. Nothing was stepped through frame by frame for these
  docs; where a frame count is given it is a typical 2D-animation figure, not a measurement of the show.
- Where a source could not be reached (one critique site sits behind a bot check) the doc says so.

## Questions

The element chats message the reference finder session with questions ("what does a water whip look like at its
tip", "how does Toph lift a slab"); answers are given as descriptions and links and appended under each doc's
"Q&A" section, so later readers find them.
